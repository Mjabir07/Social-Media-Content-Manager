# AZMIN Brand Mark

## Primary SaaS mark

File: `public/brand/azmin-mark-v2.png`

- 512 x 512 transparent PNG
- Simplified interlocking A and Z
- Designed for sidebar, favicon, app icon, avatar, login, and mobile use
- Deep navy, electric blue, and cyan palette
- Always display on a cool-white or very pale-blue tile when used over dark navy

## Original presentation artwork

File: `public/brand/azmin-source.png`

The original metallic artwork remains preserved for presentations and large-format brand material. It should not be used at small UI sizes.

## Lockup rule

Use the SaaS mark beside live HTML text:

- AZMIN
- Digital OS

Do not place the small rasterized wordmark from the original presentation artwork inside navigation.

## Generation prompt

A vector-friendly enterprise SaaS monogram based on the original interlocking AZ identity, centered and readable at 24px, with deep navy, electric blue, and cyan. No wordmark, metallic texture, bevel, shadow, 3D, mockup, border, or background texture.

Generation mode: built-in image generation using the supplied logo as the identity reference. A flat magenta background was removed locally and the result was normalized to a transparent 512px square.
