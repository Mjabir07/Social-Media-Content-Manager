# Agency Service Delivery Workflows

**Status:** Approved  
**Owner:** AZMIN Digital  
**Last updated:** 2026-08-11

## Universal agent lifecycle

Every solution area uses the same controlled lifecycle:

1. **Assess** — load client, contract, service, history, access and current state.
2. **Research** — collect approved internal/public evidence and record sources.
3. **Plan** — define scope, dependencies, risks, tasks, dates, cost and success criteria.
4. **Approve** — pause external, commercial, production or destructive actions.
5. **Execute** — perform automatic, official-API or guided manual actions.
6. **Verify** — test outputs against acceptance criteria and retain evidence.
7. **Document** — update client, service, technical and operating records.
8. **Report** — communicate results, exceptions, metrics and next actions.
9. **Monitor/Renew** — schedule recurring work, health checks, billing and renewal.

## CRM and sales

`Capture → Enrich → Qualify → Discover → Scope → Quote → Follow up → Win/Lose`

- Agent captures channel/source, contact and need.
- Qualification produces evidence, score and recommended next action.
- Approved scope produces quotation/proposal and follow-up tasks.
- Won creates/reuses the Client and creates purchased Service Engagements.
- Lost records reason and a permitted nurture path.

## Client onboarding

`Won deal → Client record → Contacts → Agreement → Billing → Access → Knowledge → Kickoff`

- Reuse an existing Client where identity matches; never create duplicates silently.
- Collect service-specific information and secrets through approved secure forms.
- Create an onboarding plan per purchased service.
- Verify responsibilities, communication channels, approvals and success measures.

## Digital Marketing & Branding

`Brand intake → Audit/research → Strategy → Campaign → Content/design → Approval → Distribution → Engagement → Analytics → Optimization`

- Submodules: brand identity, SMM, content, creative design, SEO/content marketing,
  paid media, email/WhatsApp marketing, reputation and reporting.
- Client brand context belongs to the Client/Service Engagement.
- Every published/paid/client-facing action requires approval by default.

## Websites and applications

`Discovery → Requirements → UX/content → Architecture → Build → QA/security → Preview → Approval → Deploy → Handover → Maintain`

- Repository, branch, environment, migrations and deployment evidence are retained.
- Production merge/deploy, DNS and destructive database actions require approval.

## AI and workflow automation

`Process discovery → Baseline → Automation design → Data/permission review → Prototype → Test → Approval → Activate → Observe → Improve`

- Define human fallback, idempotency, retries, rate limits and audit evidence.
- Never automate a high-risk decision merely because an API exists.

## Infrastructure, hosting and domains

`Inventory → Assess → Design → Provision → Configure → Secure → Verify → Monitor → Backup → Renew`

- Covers DNS, domains, SSL, hosting, servers, storage, backups and availability.
- Credential changes, DNS writes, production provisioning and deletion require approval.

## Email and cloud services

`Requirements → Tenant/domain verification → Licence plan → Provision → DNS → Security → Migration → Test → Handover → Renew`

- Covers Google Workspace, Microsoft 365, Zoho and hosted email/cloud services.
- Account creation, mailbox migration and DNS changes require explicit approval.

## Managed IT and support

`Request/alert → Triage → Diagnose → Plan → Approve if risky → Resolve → Verify → Communicate → Knowledge article → Follow up`

- Incidents retain impact, timeline, root cause, resolution and prevention actions.
- Remote access and destructive remediation are separately permissioned.

## Finance, billing and profitability

`Approved scope → Quote → Acceptance → Invoice → Payment → Cost allocation → Profit → Reconcile → Report`

- Agents may prepare drafts and reminders.
- Issuing invoices, recording settlements and financial corrections require approval.
- Payments, contracts and bank actions remain manual-only unless separately governed.

## Renewals and recurring service

`Service activation → Renewal schedule → Cost/price review → Reminder → Quote/invoice → Payment → Provider renewal → Verify → Next cycle`

- Renewal is tied to the Client and Service Engagement.
- Failure to renew escalates before service interruption.

## Reporting and continuous improvement

`Collect verified data → Validate quality → Compare target → Explain drivers → Recommend action → Approve → Feed next cycle`

- Reports distinguish measured facts, estimates and agent recommendations.
- Metrics and definitions are versioned and source-backed.
