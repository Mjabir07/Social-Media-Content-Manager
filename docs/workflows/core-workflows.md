# Core Workflows

## Company onboarding

1. Create the company and select relationship type.
2. Add contacts and billing information.
3. Configure Brand Profile and Company Brain.
4. Add services and agreements.
5. Connect integrations using secret references.
6. Create recurring tasks and renewals.
7. Confirm company isolation and permissions.

## Lead-to-revenue

1. Capture lead, source and associated company/partnership.
2. Qualify the lead and prepare a proposal.
3. Record acceptance and create project/service records.
4. Invoice or record the partner sale.
5. Record payment and calculate profit or commission.
6. Schedule delivery and renewal activity.

## Commission sale

1. Validate the active partnership agreement.
2. Attribute the lead to AZMIN and retain evidence.
3. Track deal stages and final closing value.
4. Record customer payment status.
5. Calculate commission using the agreement version active at closing.
6. Approve settlement and record paid/outstanding amounts.

## Website/application delivery

1. Capture and approve the requirement/specification.
2. Create project, tasks and repository.
3. Create an isolated branch/worktree per task.
4. Dispatch approved work to a coding agent.
5. Run lint, typecheck, tests and build.
6. Create preview deployment and perform QA.
7. Obtain internal/client approval.
8. Merge and deploy production.
9. Create handover, monitoring, maintenance and renewal records.

## Content-to-publishing

1. Select company and campaign.
2. Load Company Brain and selected skill.
3. Generate brief, copy, design and platform variants.
4. Validate brand/platform requirements and obtain approval.
5. Schedule using an official integration.
6. Record result, retry failures and collect metrics.

## SMM client onboarding

1. Capture a lead and select the relevant SMM service.
2. Qualify, quote and mark the lead won.
3. Complete the idempotent lead-to-client/work conversion.
4. Automatically onboard recognizable SMM services, or select **Onboard SMM**.
5. Link the Client, Company and originating Lead in one SMM account.
6. Create missing Brand Profile, Company Brain and starter content pillars.
7. Complete brand context, goals, platforms and approval policy.
8. Connect official social accounts and validate permissions.
9. Activate the first campaign only after readiness checks pass.

## Renewal workflow

1. Create renewal when a service begins.
2. Notify the owner at configured intervals.
3. Verify provider cost and client price.
4. Prepare quotation/invoice and obtain confirmation.
5. Record payment and renew the provider service.
6. Verify health and update the next renewal date.

## Agent approval workflow

1. Agent proposes an action.
2. System assigns a risk level.
3. Automatic actions run within scoped permissions.
4. Approval-required actions pause with a plain-language summary.
5. User approves, rejects or requests revision.
6. Only the approved action executes.
7. Result and evidence enter the audit trail.
