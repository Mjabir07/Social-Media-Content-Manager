# Glossary

| Term | Meaning |
| --- | --- |
| Agent | AI worker operating with defined tools, skills and permissions |
| Agent adapter | Provider connector presenting a common agent-run interface |
| Approval request | Recorded pause requiring a user decision before an action |
| AZMIN HQ | Private consolidated workspace for AZMIN Digital |
| AZMIN Pulse | AZMIN Digital's monitoring SaaS product |
| Brand Profile | Structured visual, verbal and market identity of a company |
| Company Brain | Isolated company knowledge used by approved AI skills |
| ClientService | A service sold to or managed for a company |
| Company | Own brand, client, partner, prospect or joint-venture organization |
| Integration adapter | Provider implementation behind a neutral AZMIN interface |
| MCP | Protocol used to expose tools/context to compatible agents |
| Phase | A testable delivery stage producing a useful result |
| Secret reference | Metadata pointing to a vault secret without storing its value |
| Skill | Reusable instructions, tools, checks and output rules for an agent task |
| Tenant | Top-level isolated SaaS customer/account boundary |
| Worktree | Isolated Git working directory for a branch or agent task |
