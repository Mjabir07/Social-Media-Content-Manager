# Glossary

| Term | Meaning |
| --- | --- |
| Agent | AI worker operating with defined tools, skills, policy and evidence |
| Approval request | Recorded pause requiring a human decision before an action |
| Client | Agency customer receiving one or more services |
| Client Brain | Approved client facts, brand context, requirements and instructions used by agents |
| Digital Marketing & Branding | Parent service module containing brand, strategy, content, SMM, SEO, ads, messaging and analytics |
| Operating Context | Optional own brand, employer, partner or joint venture context; currently represented by legacy Company records |
| Service Engagement | Purchased service scope linking a Client to delivery, finance, approvals and renewals |
| SMM | Social Media Management, a Digital Marketing & Branding submodule |
| Skill | Reusable instructions, tools, checks and output rules for an agent task |
| Tenant / Workspace | Top-level isolated CRM owner; each future SaaS buyer receives one |
| Workflow registry | Machine-readable inventory used to generate and validate workflow documentation |
| Worktree | Isolated Git working directory for a branch or agent task |
